# SkinSense AI Design System

## Purpose

This document defines the visual language of SkinSense AI. Every page
and component should follow these rules.

# Design Principles

-   Minimal
-   Trustworthy
-   Premium
-   Accessible
-   Consistent
-   Mobile-first

# Color System

## Brand

Primary: #3DD9EB Secondary: #00FFA3 Accent: #7C5CFC

## Background

Canvas: #050816 Surface: #0B1120 Card: rgba(255,255,255,0.05) Border:
rgba(255,255,255,0.08)

## Semantic

Success: #22C55E Warning: #F59E0B Danger: #EF4444 Info: #3B82F6

## Text

Primary: #FFFFFF Secondary: #CBD5E1 Muted: #94A3B8

# Typography

Font Family: - Plus Jakarta Sans Fallback: - Inter - Poppins

Scale - Display 64 - H1 48 - H2 36 - H3 30 - H4 24 - H5 20 - Body 16 -
Small 14 - Caption 12

Line height: 150%

# Spacing

Use an 8px spacing system.

4, 8, 16, 24, 32, 40, 48, 64, 80, 96

# Border Radius

Small: 8 Medium: 16 Large: 20 XL: 28 Pill: 999

# Shadows

Small Medium Large Glow Glass

# Glassmorphism

Backdrop Blur: 20px

Opacity: 5%

Border: rgba(255,255,255,0.08)

# Buttons

Primary Secondary Outline Ghost Danger Success

States Default Hover Active Disabled Loading

# Cards

Feature Card Prediction Card Dashboard Card Statistic Card
Recommendation Card

All cards should: - rounded corners - glass effect - hover lift - subtle
shadow - animated border glow

# Forms

Input Textarea Dropdown Checkbox Radio Switch

Include: - error state - success state - disabled state - focus ring

# Icons

Use Lucide React.

Stroke width: 2px

Icon sizes: 16 20 24 32 48

# Charts

Use Recharts.

Charts: - Bar - Line - Pie - Area - Circular Gauge

# Motion Principles

Library: Framer Motion

Duration: 0.2s--0.6s

Ease: easeOut

Use: - Fade - Slide - Scale - Stagger - Hover Lift - Page Transition

# Responsive Breakpoints

Mobile: \<640 Tablet: 640--1023 Desktop: 1024+ Wide: 1440+

# Accessibility

WCAG AA contrast. Visible focus indicators. Keyboard navigation. Reduced
motion support.

# Quality Checklist

✓ Consistent spacing ✓ Consistent typography ✓ Reusable components ✓
Responsive layouts ✓ Accessible interactions ✓ Smooth animations
