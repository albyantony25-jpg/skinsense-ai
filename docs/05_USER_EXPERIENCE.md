# 05_USER_EXPERIENCE.md

# User Experience Guidelines

## UX Goals

-   Simple
-   Trustworthy
-   Fast
-   Delightful
-   Accessible

## First Impression

Within 5 seconds the user should understand: - What SkinSense is - What
it does - How to begin

## First-Time User Flow

1.  Arrive at landing page
2.  Read headline
3.  View benefits
4.  Upload image
5.  Watch AI analysis
6.  Receive prediction
7.  Explore recommendations

## Upload Experience

Support: - Drag & Drop - Click to Browse - Preview - Replace Image -
Remove Image

Validation: - PNG/JPG/JPEG - Max size - Friendly error messages

## Loading Experience

Replace spinner with: - Animated neural network - Progress indicator -
Rotating status messages

Messages: - Loading model... - Detecting lesion... - Extracting
features... - Predicting... - Preparing report...

## Results Experience

Show: - Disease Name - Confidence - Risk Badge - Top Predictions -
Symptoms - Causes - Treatment - Recommendation

## Empty States

"No image uploaded yet."

"No scan history."

## Error States

Explain: - What happened - Why - How to fix it - Retry button

## Success States

Animated checkmark

Toast: "Analysis Complete"

## Accessibility

Keyboard navigation Screen reader labels Visible focus rings Reduced
motion

## Mobile UX

Large buttons Single-column layout Sticky upload button Comfortable
spacing

## Micro-interactions

Buttons glow Cards lift Progress animates Counters count up Images zoom
on hover

## UX Checklist

✓ Clear CTA ✓ Responsive ✓ Fast feedback ✓ Helpful errors ✓ Trustworthy
wording ✓ Consistent navigation ✓ Smooth animations
