# Portfolio Guide

## Elevator Pitch

SkinSense AI is a premium AI-powered skin disease classification web
application built with React, Tailwind CSS, Flask, and TensorFlow. The
focus is on combining accurate machine learning with a polished,
accessible user experience.

## Resume Bullet Points

-   Designed and developed a responsive AI healthcare web application.
-   Integrated a Flask + TensorFlow inference API with a modern React
    frontend.
-   Built reusable UI components following a scalable design system.
-   Implemented accessible, mobile-first, animated interfaces using
    Tailwind CSS and Framer Motion.
