# Accessibility Guide

## Goal

Meet WCAG 2.2 AA wherever practical.

## Principles

-   Perceivable
-   Operable
-   Understandable
-   Robust

## Keyboard Navigation

-   Tab through all interactive elements.
-   Visible focus ring.
-   Escape closes dialogs.
-   Enter activates primary actions.

## Screen Readers

-   Semantic HTML
-   aria-label on icon buttons
-   aria-live for prediction status
-   alt text for images

## Color & Contrast

-   Minimum AA contrast.
-   Never rely on color alone.
-   Pair colors with icons/text.

## Forms

-   Labels for every field.
-   Helpful validation.
-   Error text linked with inputs.

## Motion

-   Respect prefers-reduced-motion.
-   Disable decorative effects when requested.

## Responsive Accessibility

-   Touch targets ≥44px.
-   Readable font sizes.
-   Zoom to 200% without breaking layout.

## Accessibility Checklist

-   Keyboard only navigation
-   Focus management
-   ARIA landmarks
-   Contrast tested
-   Screen reader tested
-   Accessible charts
