# Component Library

## Principles

-   Reusable
-   Accessible
-   Responsive
-   Animated
-   Consistent

## Layout Components

-   AppShell
-   Navbar
-   Footer
-   SectionContainer
-   Grid
-   Stack

## Navigation

### Navbar

Purpose: Primary navigation. States: default, scrolled, mobile open.
Animation: blur + shrink on scroll.

### Mobile Menu

Fullscreen drawer with staggered links.

## Hero

-   Badge
-   Heading
-   Description
-   CTA Buttons
-   Hero Illustration
-   Stats Row

## Buttons

Variants: - Primary - Secondary - Outline - Ghost - Danger - Success

States: default, hover, active, disabled, loading.

Every component must: - support keyboard - have focus styles - use
semantic HTML - include ARIA labels where needed.
