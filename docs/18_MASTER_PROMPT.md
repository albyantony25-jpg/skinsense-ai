> Use this prompt with Antigravity, Cursor, Claude Code or GitHub

## Objective

Transform the existing SkinSense frontend into a premium AI healthcare
SaaS interface.

### Non-negotiable Rules

-   Preserve the existing Flask backend.
-   Preserve all API endpoints.
-   Preserve prediction logic.
-   Do not modify ML code.
-   Improve only the frontend architecture, UI and UX.
