# 03_BRAND_GUIDELINES.md

# SkinSense AI Brand Guidelines

## Brand Personality

Professional

Trustworthy

Innovative

Minimal

Human-centered

Intelligent

Calm

Reliable

------------------------------------------------------------------------

# Brand Mission

Use artificial intelligence to make early skin health screening more
approachable through a beautiful and trustworthy digital experience.

------------------------------------------------------------------------

# Brand Voice

Friendly

Clear

Simple

Never alarming.

Always informative.

Avoid technical jargon where possible.

Example:

❌ "Inference completed."

✅ "Your analysis is ready."

------------------------------------------------------------------------

# Logo

Simple wordmark:

SkinSense AI

Use a medical-inspired symbol such as a shield, cross, or neural spark.

Do not overcomplicate the logo.

------------------------------------------------------------------------

# Visual Style

Inspired by: - Apple - OpenAI - Linear - Vercel

Use: - Glassmorphism - Soft gradients - Rounded corners - Minimal
icons - Generous whitespace

------------------------------------------------------------------------

# Photography

Use: - Dermatology - Healthcare - Clean clinical environments - Abstract
AI visuals

Avoid: - Graphic medical imagery - Busy stock photos

------------------------------------------------------------------------

# Iconography

Use Lucide React.

Consistent line icons only.

------------------------------------------------------------------------

# Illustration Style

Flat + subtle 3D.

Medical but friendly.

Blue, cyan and emerald accents.

------------------------------------------------------------------------

# Writing Guidelines

Buttons: - Upload Image - Analyze Image - Download Report

Never use vague labels like "Submit".

------------------------------------------------------------------------

# Microcopy

Loading: - Preparing AI... - Analyzing image... - Generating results...

Empty state: "No image uploaded yet."

Success: "Analysis complete."

Error: "We couldn't analyze this image. Please try another photo."

------------------------------------------------------------------------

# Trust Signals

Display: - AI Accuracy - Dataset - Prediction Confidence - Explainable
AI - Privacy First

------------------------------------------------------------------------

# Brand Promise

Beautiful design builds trust.

Trust encourages adoption.

Every interaction should reinforce confidence in the product.
